# Product Brief — 蒸汽都市

Last updated: 2026-08-10 · Baseline: V1.10 修订⑦

> **非规范历史**：产品定位的稳定摘要已并入 README、Requirements 与 Decisions；当前能力和限制只看 `../status.md`。

## 一句话定义

一款零依赖、点开即玩的浏览器工业时代城市模拟经营游戏：玩家在随机海岛上规划道路、物流与生产链，通过满足分阶层居民需求推动城市发展；项目同时用于展示以 AI agent 组织产品、工程、测试和迭代的能力。

## 目标用户

- **主要用户 A：模拟经营玩家**——关注生产链、布局、供需和扩张节奏
- **主要用户 B：潜在雇主/同行**——关注需求拆解、机制正确性、工程组织与验证证据
- **作者自己**——作品集项目和长期机制实验场

## 价值主张

- 无安装、无注册，打开网页即可体验完整模拟循环
- 以清晰的 2D 方块地图呈现多格建筑、道路服务和复杂生产链
- 核心引擎可在 Node 中确定性测试，机制变更有文档和验收记录
- 数据与逻辑分离，人工可通过 Excel 校准建筑和需求参数

## 当前玩家旅程

1. 打开空岛新游戏：10000 金币、60 木材、300 鱼、0 人口、0 建筑
2. 从农民页建造仓库，建立物流服务起点
3. 建造农民住宅、道路和渔场，让住户获得鱼需求
4. 补工作服与烈酒等生产链；需求满足后住户逐步增加
5. 农民达到 50 解锁工人，通过住宅升级和工人链继续发展
6. 人口达到 150 解锁工匠；工程师/投资人数据存在但当前锁定
7. 在道路覆盖、劳动力、原料、维护费和开发度之间做空间与经济权衡
8. 可通过公告、机制速览、生产链、图例和留言板获取帮助或反馈

## 当前产品边界

### 已实现

- 随机 128×128 单岛地图与种子复现
- 平地、水域、山脉、黏土和六类矿脉；森林地形已移除
- 64 建筑、63 商品/资源、5 阶层数据
- 多格 footprint、中心锚点四向旋转、移动、拆除
- 土路/石板路、断连停工、服务沿道路传播
- 多仓库接入同一总资源池；生产建筑必须在仓库物流覆盖内
- 周期制生产、劳动力、维护费、开发度效率
- 每阶层独立需求、离散 Influx 住户、需求驱动收入、幸福度
- 住宅升级链、目标引导、速度与时间/昼夜
- localStorage 自动保存与安全重置
- Cloudflare Pages 发布；留言板使用 Worker + D1，离线失败不阻塞游戏

### 当前限制

- 工程师和投资人 `unlockAt=999999`，玩家流程暂不开启
- 皮草大衣、朗姆酒、咖啡、电力、大学、剧院等部分需求缺少可用建筑，相关高阶人口不能形成完整闭环
- 无贸易、船运、多岛、AI 对手、战争、影响力和矿脉储量
- 库存为全局总资源池，无仓库容量和运输车辆时间模型
- 桌面优先；紧凑视口的首屏相机、顶部栏和欢迎弹窗仍待适配

## 明确非目标（当前版本）

1. 直接使用任何商业游戏的官方美术、角色、地名或受保护文本
2. 多人、账号、排行榜和云存档
3. 完整 3D/等距美术表现
4. 在缺失需求建筑完成前开放工程师/投资人
5. 自动把外部资料数值写入用户的人工核查表

## 成功信号

- 新玩家无需外部说明即可完成“仓库 → 住宅 → 渔场 → 工人”路径
- 生产、需求、人口、收入和劳动力形成可恢复的经济闭环
- 关键机制具有自动化测试，顶层调用链与浏览器实际行为一致
- 文档、代码、测试和玩家教程保持同一规则
- 真实玩家能持续游玩、留言并报告可复现问题
